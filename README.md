# Vivek Suyambu

Personal site for Vivek Suyambu, a software engineer in Bengaluru. One static page: writing, selected work, stack, and experience.

Live at [keviveks.github.io](https://keviveks.github.io).

## Local preview

```bash
python3 -m http.server 8765
```

Open [http://127.0.0.1:8765](http://127.0.0.1:8765).

## Layout

- `index.html` — page content
- `assets/css/style.css` — layout, type, and motion
- `assets/js/site.js` — scroll reveal and the timeline draw
